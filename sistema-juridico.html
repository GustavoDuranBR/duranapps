Jurix (v2.0)

Software Desktop de Alta Performance para Gestão Jurídica, Processos e Prazos

📋 O que é o Jurix?

O Jurix (antigo Sistema Jurídico) é a evolução definitiva para a gestão do seu escritório de advocacia. Projetado para ser robusto, rápido e 100% focado em produtividade, ele centraliza cadastros de clientes, andamentos de processos, automação de documentos e controle de agenda num ambiente altamente seguro.

Arquitetura em Rede (Multi-Máquinas)

Trabalhe em equipe sem lentidão. O Jurix possui um configurador inteligente que permite implementar o sistema em rede local de forma automática.

  • Servidor Principal: Centraliza o banco de dados de forma segura.
  • Estações de Trabalho: Recepção e outras salas acessam os dados em tempo real.
  • Sincronização imediata entre todos os computadores do escritório.

Radar de Prazos e Agenda

Nunca mais perca um prazo importante. O novo módulo de Agenda funciona como um autêntico "radar" para o seu escritório.

  • Notificações visuais e automáticas de audiências e prazos processuais.
  • Visualização clara dos compromissos diários e semanais.
  • Histórico de andamentos integrado diretamente na ficha de cada cliente.

Automação de Documentos (Integração Word)

Gere contratos, procurações e termos com um único clique. O Jurix preenche automaticamente os modelos do escritório com os dados do cliente selecionado.

  • Modelos blindados (.docx) que preservam a formatação visual do seu escritório.
  • Geração automática de arquivos PDF prontos para impressão ou assinatura digital.
  • Integração nativa e otimizada com o LibreOffice.

🔐 Segurança, Acessos e Licenciamento

Os seus dados são confidenciais e estão protegidos por múltiplas camadas de segurança.

  • Sistema Multiusuário: Perfis de Admin (controle total), Super (edição) e Padrão (apenas consulta).
  • Proteção LGPD: Banco de dados isolado e armazenado localmente na sua máquina, sem exposição à nuvem pública.
  • Ativação por Hardware: Licenciamento profissional atrelado ao ID da placa-mãe da máquina, garantindo total segurança contra pirataria.

💾 Backup e Instalador Inteligente

O sistema protege o seu escritório contra perda de dados através de rotinas automatizadas e suporte inteligente.

  • Migração Passiva: Detecção e migração automática de dados de versões antigas (SistemaJuridico).
  • Backup Integrado: Cópias de segurança geradas automaticamente antes de atualizações.
  • Acesso Mobile: Acesso via navegador (celular/tablet) pela rede Wi-Fi para consultas rápidas.

📁 Localização dos Dados

Os dados estruturais do sistema (banco de dados SQLite) estão armazenados de forma segura no caminho:

%LOCALAPPDATA%\Jurix\data
